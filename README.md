# 提携企業

業務提携先を「自衛隊」「企業」「企業（チラシのみ）」「店舗」に分けて、企画書・契約書・写真・訪問履歴をまとめて管理するアプリです。

GitHub Pages で公開し、データとファイルは Firebase に保存します。ログインした人なら、どのパソコン・スマートフォンからでも同じ URL で同じ内容を見て編集できます。ほかの人の変更は自動で画面に反映されます。

## 使い方

- **提携先を追加**：右上のボタンから、カテゴリー・名称・ステータスを登録
- **概要**：担当者、連絡先、所在地、契約期間、メモ（契約終了30日前から「契約残り○日」を表示）
- **企画書・契約書**：PDF・画像をドラッグ＆ドロップで追加（1ファイル50MBまで）
- **写真**：JPEG・PNG・GIF・WebP を一覧表示、クリックで拡大
- **訪問履歴**：訪問日・訪問者・目的・内容を記録
- **バックアップ**：提携先・訪問履歴・ファイル一覧を1つのファイル（.json）に保存

## 初回の設定（管理者が1回だけ）

1. [Firebase コンソール](https://console.firebase.google.com)でプロジェクトを作成
2. 料金プランを Blaze に変更（ファイル保存の Storage に必要。予算アラートの設定を推奨）
3. Authentication で「メール/パスワード」を有効にし、設定の「ユーザーアクション」で新規登録をオフ。承認済みドメインに GitHub Pages のドメインを追加
4. Firestore Database を作成し、ルールに [`firebase/firestore.rules`](firebase/firestore.rules) を貼り付けて公開
5. Storage を開始し、ルールに [`firebase/storage.rules`](firebase/storage.rules) を貼り付けて公開
6. プロジェクトの設定でウェブアプリを登録し、表示された firebaseConfig の値を [`config.js`](config.js) に入れる

## 使う人を追加する

Firebase コンソールの「Authentication」→「Users」→「ユーザーを追加」で、メールアドレスとパスワードを登録します。パスワードの再設定や削除も同じ画面から行えます。

## 注意

- config.js の値（apiKey など）はブラウザに置く前提の公開用の値です。データはログインした人だけが読み書きできるよう、セキュリティルールで保護しています。
- アップロードしたファイルは、ファイルごとのリンク（推測できない長い URL）で表示しています。リンクを知っている人はログインなしでも開けるので、ファイルのリンクを外部に共有しないでください。

## ファイル構成

- `index.html` … アプリ本体
- `config.js` … Firebase の接続先
- `firebase/firestore.rules` … データベースのアクセスルール
- `firebase/storage.rules` … ファイル置き場のアクセスルール
