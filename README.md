# 提携企業

業務提携先を「自衛隊」「企業」「企業（チラシのみ）」「店舗」に分けて、企画書・契約書・写真・訪問履歴をまとめて管理するアプリです。

## 使い方

GitHub Pages で公開した URL をブラウザで開くだけで使えます。インストールやサーバーは不要です。

- **提携先を追加**：右上のボタンから、カテゴリー・名称・ステータスを登録
- **概要**：担当者、連絡先、所在地、契約期間、メモ（契約終了30日前から「契約残り○日」を表示）
- **企画書・契約書**：PDF・画像をドラッグ＆ドロップで追加
- **写真**：JPEG・PNG・GIF・WebP を一覧表示、クリックで拡大
- **訪問履歴**：訪問日・訪問者・目的・内容を記録

## データの保存場所について

データとファイルは、**開いたブラウザの中（IndexedDB）にだけ保存されます**。GitHub やほかの場所には送信されません。

- ほかのパソコン・スマートフォン・ブラウザからは見えません
- ブラウザの履歴やサイトデータを消すと失われます
- 右上の「バックアップ」から、すべてのデータを1つのファイル（.json）に保存・復元できます。定期的に保存してください
